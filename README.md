# 向豪和赵雅珊的厨房

这是可直接发布到 GitHub Pages 的静态网站。无需安装依赖或运行构建。

发布时将本目录的文件上传到一个新仓库的根目录（index.html 应位于根目录），然后在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。保留 .nojekyll 文件。

使用流程：主人点击分享菜单并发送新生成的完整链接；朋友打开后选菜、填写名字和备注，保存并生成新的订单链接回传；主人打开订单链接并保存到自己的订单。

浏览器中的菜品和订单保存在本机，不会自动同步。菜单链接携带生成时的菜单文字、食材及步骤，不包含自上传大图。菜单编辑后需要重新分享。链接回传不代表自动接单，需要朋友手动发送。

正式启用前，必须在实际微信及手机网络中测试首页、菜单链接与订单回传流程。
